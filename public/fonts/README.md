# Euclid Circular B Fonts

This directory should contain the licensed Euclid Circular B font files for the ACKO OMNI Support application.

## Required Font Files

Place the following WOFF2 font files in this directory:

- `EuclidCircularB-Regular-WebXL.woff2`
- `EuclidCircularB-RegularItalic-WebXL.woff2` 
- `EuclidCircularB-Medium-WebXL.woff2`
- `EuclidCircularB-MediumItalic-WebXL.woff2`
- `EuclidCircularB-Semibold-WebXL.woff2`
- `EuclidCircularB-SemiboldItalic-WebXL.woff2`

## Font Fallback

The application is configured to use:
1. **Euclid Circular B** (when font files are available)
2. **Inter** (loaded from Google Fonts as fallback)
3. System fonts as ultimate fallback

## Current Status

❌ **Font files not present** - Application currently using Inter fallback font.
